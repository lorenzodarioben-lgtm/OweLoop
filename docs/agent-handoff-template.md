# Agent handoff template

Use this template when handing a task to another human contributor or coding agent.

```md
## Task objective

## Branch

## Base commit

## Summary of changes

## Files changed

## Architecture decisions

## Database migrations

## Dependencies added or removed

## Commands run

## Test results

## Known limitations

## Security review

## Follow-up work

## Commit hash

## Final Git status
```

State explicitly when a section is not applicable. Link relevant issues, pull requests, documentation, or migration files so the next contributor does not have to infer context.
